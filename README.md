# Current Meter — Linux Server

## Описание

Серверная часть проекта Current Meter предназначена для приёма, обработки и хранения результатов измерения электрического тока, получаемых от микроконтроллера ESP32.

Сервер работает на Linux (Ubuntu) и использует Flask для обработки HTTP-запросов и SQLite для хранения измерений.

## Используемые технологии

- **Python** — основной язык программирования.
- **Flask** — создание веб-сервера и обработка HTTP-запросов.
- **SQLite** — хранение результатов измерений.
- **HTML / CSS / JavaScript** — веб-интерфейс для отображения данных.

## Принцип работы

1. ESP32 считывает данные с АЦП ADS1115 и рассчитывает значение тока.
2. Измерения объединяются в пакеты и передаются по Wi-Fi на Linux-сервер с помощью HTTP POST-запросов.
3. Flask принимает полученные данные, проверяет их формат и сохраняет в базу данных SQLite.
4. Веб-интерфейс получает сохранённые измерения от сервера и отображает текущий ток, график и таблицу результатов.
5. При необходимости данные можно экспортировать в CSV-файл.

## Структура проекта

```text
server/
├── server.py
├── requirements.txt
├── measurements.db
├── templates/
│   └── index.html
└── static/
    ├── style.css
    └── script.js
```

- `server.py` — основная программа: запуск Flask, обработка запросов, работа с базой данных и передача данных веб-интерфейсу.
- `requirements.txt` — список необходимых Python-библиотек.
- `measurements.db` — база данных с результатами измерений (создаётся автоматически).
- `templates/index.html` — структура веб-страницы.
- `static/style.css` — оформление веб-интерфейса.
- `static/script.js` — получение и визуализация измерений.

## HTTP-маршруты

| Маршрут | Назначение |
|---|---|
| `/` | Открытие веб-интерфейса |
| `/health` | Проверка работоспособности сервера |
| `/measurement` | Приём измерений от ESP32 |
| `/api/data` | Получение списка измерений |
| `/api/latest` | Получение последнего измерения |
| `/api/export.csv` | Экспорт данных в CSV |

## Установка и запуск

Создание виртуального окружения и установка зависимостей:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск сервера:

```bash
python server.py
```

По умолчанию Flask принимает подключения на порту `5000` и доступен по адресу:

```text
http://<SERVER_IP>:5000/
```

Для проверки работоспособности:

```text
http://<SERVER_IP>:5000/health
```

## Хранение данных

Каждое измерение сохраняется в SQLite и содержит:

- `id` — уникальный номер записи;
- `device_time_ms` — время измерения на ESP32 в миллисекундах;
- `current_uA` — измеренный ток в микроамперах;
- `received_at` — время получения записи сервером.

База данных создаётся автоматически при первом запуске программы.
